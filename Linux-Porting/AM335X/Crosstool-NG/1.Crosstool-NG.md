# BeagleBone Black 工具鏈建置（crosstool-NG）

## 1. 環境資訊
- Host OS: Ubuntu 22.04, x64
- Target board: BeagleBone Black, TI AM335x Cortex-A8
- 參考資料: https://docs.beagleboard.org/boards/beaglebone/black/ch07.html

## 2. 開發板與硬體準備
需要準備以下項目：
1. BeagleBone Black TI AM335x Cortex-A8 開發板
2. USB-to-TTL 3.3V 轉接板（可用於序列埠 console）
   - BeagleBone J1：PIN1 = GND, PIN4 = RX, PIN5 = TX
3. 5V 電源供應器
4. microSD 卡（至少 4GB）

<img src="../../Images/Beagle-bone.jpg" width="50%" />

## 3. 自行組裝的四大元素
要建立一套完整的 Linux 系統，需要準備：
1. Toolchain
2. Bootloader（U-Boot）
3. Kernel
4. Root filesystem（rootfs）

## 5. 建立 crosstool-NG
我們使用 crosstool-NG 來建立 BeagleBone Black 的交叉編譯工具鏈。

### 5.1 下載並編譯 crosstool-NG

```bash
git clone https://github.com/crosstool-ng/crosstool-ng.git
cd crosstool-ng
git checkout crosstool-ng-1.29.0

./bootstrap
./configure --prefix=${PWD}
make
make install
```

> 若使用 `--prefix=${PWD}`，會將 crosstool-NG 安裝到目前目錄下。

## 6. 建立 BeagleBone Black 目標工具鏈

```bash
# ./bin/ct-ng list-samples
./bin/ct-ng arm-cortex_a8-linux-gnueabi
./bin/ct-ng menuconfig
```

### 進入 menuconfig 後設定
- Paths and misc options
  - 取消 `Render the toolchain read-only`
- Toolchain options
  - Floating point -> 選擇 `hardware (FPU)`
  - Use specific FPU -> 輸入 `neon`

設定完成後，存檔並離開。

### NEON 與 FPU

NEON 是 ARM 的 Advanced SIMD 指令集，可一次處理多筆整數或浮點資料，適合音訊、影像與數值運算。它不是一般 FPU 的替代品：一般浮點運算使用 VFP/FPU，而 NEON 用於向量化運算。對 Cortex-A8，選擇硬體 FPU 與 `neon` 可使編譯器產生符合處理器能力的指令。

### 使用 Alpine rootfs 時的 musl 設定

Alpine Linux 使用 musl libc。交叉工具鏈的 C library 必須同樣選擇 musl，否則以 glibc 建置的程式無法直接在 Alpine rootfs 執行。

在 `ct-ng menuconfig` 設定：

```text
C-library  ---> C library (musl)
Debug facilities  ---> [ ] ltrace
Debug facilities  ---> gdb  ---> [ ] Native gdb
```

- `C library (musl)`：讓目標程式連結 musl，與 Alpine 使用者空間相容。
- 取消 `ltrace`：減少工具鏈建置的相依套件與時間；除非目標板需要追蹤函式庫呼叫，否則可不建置。
- 取消 `Native gdb`：不在目標板安裝 gdb server 端工具，降低 rootfs 與工具鏈大小；除錯可在主機使用交叉 `gdb` 搭配 `gdbserver`。

## 7. 編譯工具鏈
編譯需要網路，因為工具鏈會下載對應的套件來源：

```bash
./bin/ct-ng build
```

這一步大約需要 30 分鐘左右，視網路與機器效能而定。

---

## 8. 工具鏈輸出位置
完成後，BeagleBone Black 的交叉工具鏈會放在：

```bash
~/x-tools/arm-cortex_a8-linux-gnueabi
```

這個目錄中的工具鏈可用來編譯 AM335x 平台相關的 Linux 程式與模組。
