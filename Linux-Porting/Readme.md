這個系列的目標是：
- 了解 Linux 系統移植的基本流程
- 學習交叉編譯、Bootloader、Kernel、rootfs 的整合方式
- 透過實作逐步建立一個可運作的嵌入式系統
- 利用 AI 協助理解書中概念、查找資料與驗證步驟

後續會依序整理相關主題與實作紀錄。
